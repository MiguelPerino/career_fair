# Atlas de Tecnologia — Feira de Profissões 2026

Página única em HTML/CSS/JS que apresenta, em formato de guia de campo, as principais trilhas de tecnologia para estudantes do ensino médio: áreas de atuação, graduações, carreiras, mercado de trabalho e o impacto da IA — feita para acompanhar um estande na Feira de Profissões.

🔗 **[Ver página](https://SEU-USUARIO.github.io/SEU-REPOSITORIO/)** (atualize o link após publicar)

## Conteúdo

- **Áreas** — as 6 grandes frentes de tecnologia (software, dados/IA, segurança, cloud/infra, hardware/IoT, produto/UX) e os principais mitos sobre a área.
- **Cursos** — comparação entre Ciência da Computação, Sistemas de Informação, Engenharia de Computação, Engenharia de Software e ADS.
- **Carreiras** — 12 papéis comuns no mercado, do front-end à pesquisa.
- **Mercado** — números do setor de TIC no Brasil (Brasscom 2025) e tendências globais (WEF Future of Jobs 2025).
- **IA e futuro** — o que a IA já ajuda a fazer, o que continua precisando de gente, e um teste rápido interativo que sugere um curso.
- **Comece agora** — passos práticos e links para começar a programar hoje.

## Como usar

O projeto é um único arquivo estático, sem build nem dependências além das fontes do Google Fonts (carregadas via CDN).

### Rodar localmente

Basta abrir o arquivo no navegador:

```bash
open atlas-tecnologia.html   # macOS
# ou dê duplo clique no arquivo
```
## Tecnologias

- HTML5 + CSS3 (sem framework)
- JavaScript puro (scroll reveal e teste rápido interativo)
- Fontes: [Bitter](https://fonts.google.com/specimen/Bitter), [Inter](https://fonts.google.com/specimen/Inter) e [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono), via Google Fonts

## Fontes dos dados

- Graduações: MEC — Resolução CNE/CES nº 5/2016
- Mercado brasileiro: Brasscom — Relatório Setorial 2025
- Tendências globais: World Economic Forum — Future of Jobs 2025

Dados consultados em 28/08/2026.
